* Overview
:PROPERTIES:
:CUSTOM_ID: overview
:END:
graylib 0.7 moved from raylib 6.0 to raylib 6.2, from raygui 4.0 (master of April 2026) to raygui master (5.1-dev, the raygui raylib 6.2 ships in its examples), and to the current rpng and rres masters. raudio had no upstream change. This page walks the raylib 6.2 =CHANGELOG= and raygui 5's change list entry by entry and records, for each one that touches what graylib can see, the graylib API that exposes it, the fix graylib needed, or why nothing applies. Pure bug fixes inside raylib are inherited by every graylib wrapper that calls the fixed function and are listed by module rather than one by one.

Status words used below:

- *Wrapped*: a graylib function or property exposes the feature.
- *Fixed*: graylib changed to keep working (or to work correctly) with the new behaviour.
- *graylib implementation*: raylib 6.2's version is missing or broken, so graylib implements the feature itself.
- *Inherited*: a raylib fix that graylib gets by calling the function; nothing to wrap.
- *Not applicable*: platforms, backends, build systems or languages graylib does not use.

* rcore

:CUSTOM_ID: rcore
:END:

|----------------------------------------------------------------+------------------------+--------------------------------------------------------------------------------------------------------------------------------|
| ADDED =IsPathDirectory()=                                       | Wrapped                | =grl_fs_is_path_directory()=; also requires the path to exist (raylib's is only =!IsPathFile()=)                              |
| ADDED =IsPathAbsolute()=                                        | Wrapped                | =grl_fs_is_path_absolute()=                                                                                                   |
| ADDED =IsFileHidden()=                                          | Wrapped                | =grl_fs_is_file_hidden()=; libregnum's editor uses it to hide files                                                           |
| REVIEWED =File*()= return values (0 on success)                 | Fixed                  | =grl_fs_file_copy/text_replace/change_directory= results; =file_copy= also rejects 6.2's false success for a missing source |
| REVIEWED =FileMove()= / =FileCopy()= security                   | Fixed                  | =grl_fs_file_move()= renames, else checked copy + remove                                                                       |
| REVIEWED =GetPrevDirectoryPath()= side cases                    | Inherited              | ="/a"= now gives ="/"=; test and docs updated                                                                                  |
| REVIEWED =ComputeSHA1/SHA256()=, const parameters               | Not applicable         | graylib does not wrap the hash functions (GLib's =GChecksum= covers them)                                                     |
| REVIEWED =GetFPS()=, =GetCurrentMonitor()=, =SetMousePosition()= | Inherited              | through =grl_window_*= / =grl_input_*=                                                                                         |
| REVIEWED =OpenURL()=, =TakeScreenshot()=, automation events     | Not applicable         | not wrapped by graylib                                                                                                         |
| [GLFW] =GetClipboardImage()= X11 connection and leak            | Wrapped                | =grl_window_get_clipboard_image()=, guarded to X11/Windows (the GLFW Wayland path would run X11 code without a display)       |
| [GLFW] window, focus, borderless and mouse-position fixes       | Inherited              |                                                                                                                                |
| [Win32] MSAA, =IsKeyPressedRepeat()=, clipboard, =SetMousePosition()= | Not applicable   | for raylib's native Win32 backend; graylib builds the GLFW backend, where these already work (=grl_input_is_key_pressed_repeat()=, ...) |
| [SDL], [DRM], [Web], [Android], [Emscripten], [RGFW]            | Not applicable         | graylib builds the desktop GLFW backend                                                                                        |

* Tests
:PROPERTIES:
:CUSTOM_ID: tests
:END:
=tests/test-raylib62.c= covers the wrapped and graylib-implemented entries above: path predicates and file results, image blits (including rotation), gradients and line strips, =.pep= round trips and rejections, rotated image text, contrast rounding, the TABBAR control and the new style flags, binary styles and icon sets from memory (valid and malformed), rlsw double buffering and its identification strings and, with a display, the new outline and gradient draws read back from a render texture, float render targets and the clipboard image. The rest of the suite covers the fixed entries (=test-fs=, =test-text=, =test-model-skinning=, =test-software-renderer=, =test-fast2d=).
