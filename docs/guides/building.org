* Building Graylib
:PROPERTIES:
:CUSTOM_ID: building-graylib
:END:
This guide covers all aspects of building Graylib from source.

** Build Configuration
:PROPERTIES:
:CUSTOM_ID: build-configuration
:END:
Build options are configured in =config.mk=. You can override them on the command line:

*** Version Settings
:PROPERTIES:
:CUSTOM_ID: version-settings
:END:
| Variable        | Default | Description          |
|-----------------+---------+----------------------|
| =VERSION_MAJOR= | 0       | Major version number |
| =VERSION_MINOR= | 1       | Minor version number |
| =VERSION_MICRO= | 0       | Micro version number |
| =API_VERSION=   | 1       | API version for GIR  |

*** Directory Settings
:PROPERTIES:
:CUSTOM_ID: directory-settings
:END:
| Variable       | Default                      | Description                    |
|----------------+------------------------------+--------------------------------|
| =PREFIX=       | =/usr/local=                 | Installation prefix            |
| =LIBDIR=       | =$(PREFIX)/lib=              | Library installation directory |
| =INCLUDEDIR=   | =$(PREFIX)/include=          | Header installation directory  |
| =PKGCONFIGDIR= | =$(LIBDIR)/pkgconfig=        | pkg-config file directory      |
| =GIRDIR=       | =$(DATADIR)/gir-1.0=         | GIR file directory             |
| =TYPELIBDIR=   | =$(LIBDIR)/girepository-1.0= | Typelib directory              |

*** Build Options
:PROPERTIES:
:CUSTOM_ID: build-options
:END:
| Variable         | Default | Description                          |
|------------------+---------+--------------------------------------|
| =BUILD_SHARED=   | 1       | Build shared library                 |
| =BUILD_STATIC=   | 1       | Build static library                 |
| =BUILD_GIR=      | 1       | Generate GObject Introspection files |
| =BUILD_TESTS=    | 1       | Build unit tests                     |
| =BUILD_EXAMPLES= | 1       | Build example programs               |
| =BUILD_DOCS=     | 0       | Generate API documentation           |
| =RAYLIB_SHARED=  | 0       | Link against system raylib           |
| =WAYLAND=        | auto    | GLFW Wayland backend (auto, 1, 0)    |
| =DEBUG=          | 0       | Enable debug build                   |
| =WINDOWS=        | 0       | Cross-compile for 64-bit Windows     |
| =CROSS=          | (empty) | Cross-compilation toolchain prefix   |
| =BUILDDIR=       | =build= | Output directory (objects, libraries, GIR) |
| =RAYLIB_BUILD_DIR= | =deps/raylib/src= | Where the embedded raylib is compiled |
| =RAYLIB_PLATFORM= | =PLATFORM_DESKTOP= | raylib's =PLATFORM= for the embedded build |
| =RAYLIB_EXTRA_FLAGS= | (empty) | Extra variables for raylib's own make |

=BUILDDIR=, =RAYLIB_BUILD_DIR=, =RAYLIB_PLATFORM= and =RAYLIB_EXTRA_FLAGS= exist so an embedder can keep several configurations side by side; see [[#out-of-tree-builds][Out-of-tree builds]].

** Debug Builds
:PROPERTIES:
:CUSTOM_ID: debug-builds
:END:
For debugging with gdb, build with =DEBUG=1=:

#+begin_src sh
make DEBUG=1
#+end_src

This enables:

- =-g3= for maximum debug information
- =-O0= to disable optimizations
- =-fno-omit-frame-pointer= for better stack traces
- =GRL_DEBUG= macro defined

Example debugging session:

#+begin_src sh
# Build with debug symbols
make DEBUG=1

# Run example under gdb
gdb ./examples/basic-window
(gdb) run
(gdb) bt   # backtrace on crash
#+end_src

** Using System raylib
:PROPERTIES:
:CUSTOM_ID: using-system-raylib
:END:
By default, Graylib builds raylib from the bundled submodule. To use system raylib:

#+begin_src sh
# Ensure raylib is installed
sudo dnf install raylib-devel

# Build with system raylib
make RAYLIB_SHARED=1
#+end_src

** Wayland

On Linux the embedded raylib is built with GLFW's X11 backend and, with =WAYLAND=auto= (the default) when =wayland-client=, =wayland-cursor=, =wayland-egl=, =xkbcommon= and =wayland-scanner= are installed, its Wayland backend as well (raylib's own =GLFW_LINUX_ENABLE_WAYLAND=TRUE=; raylib's sources are not changed, its generated protocol headers are gitignored).  GLFW then picks Wayland inside a Wayland session and X11 elsewhere.  =WAYLAND=1= requires the backend, =WAYLAND=0= builds X11 only.  Changing the setting rebuilds raylib (=build/.raylib-platform= records =linux= or =linux+wayland=).

Why it matters: a disabled cursor (mouse look) on Wayland uses the pointer-constraints and relative-pointer protocols, a real lock.  The X11 path under XWayland only emulates the grab by warping the pointer and stutters at the window edge.

Fedora packages: =wayland-devel libxkbcommon-devel=.  On Wayland GLFW reports (as warnings) that window positions cannot be read or set; compositors place windows themselves.

When using system raylib:

- pkg-config is used to find raylib
- The bundled raylib is not built
- Make sure raylib 6.2 is installed (graylib uses API added in 6.2)
- The embedded build pins =SUPPORT_GPU_SKINNING=0= (see =RAYLIB_FEATURE_FLAGS= in =rules.mk=); a system raylib keeps whatever it was built with

** Out-of-tree builds
:PROPERTIES:
:CUSTOM_ID: out-of-tree-builds
:END:
By default graylib builds into =build/= and the embedded raylib inside its own submodule (raylib's Makefile writes its objects, =libraylib.a= and the generated Wayland protocol headers next to its sources). Two variables move both, so several configurations can coexist; libregnum uses them to give every cross target its own copy (=build/<type>-<target>/deps/= in libregnum):

#+begin_src sh
make BUILDDIR=/tmp/gl-arm64 RAYLIB_BUILD_DIR=/tmp/raylib-arm64 \
     CC=aarch64-linux-gnu-gcc RAYLIB_EXTRA_FLAGS='CC=aarch64-linux-gnu-gcc AR=aarch64-linux-gnu-ar'
#+end_src

- =BUILDDIR= replaces =build/= for objects, libraries, GIR and the rebuild markers.
- =RAYLIB_BUILD_DIR=, when it is not the submodule's =src/=, receives an =rsync= copy of raylib's sources (objects, archives and generated protocol headers excluded) on every build, and raylib is rebuilt whenever that copy changed, its archive is missing or the rebuild tag differs. An unchanged tree is a no-op, so nothing downstream relinks. An =rsync= failure fails the build. =make raylib-clean= deletes the copy.
- =RAYLIB_PLATFORM= is passed as raylib's =PLATFORM= (=PLATFORM_ANDROID= for Android).
- =RAYLIB_EXTRA_FLAGS= is appended to raylib's make command line (a cross toolchain, the Android NDK's =ANDROID_NDK=/=ANDROID_API_VERSION=, =GRAPHICS=...). A non-desktop platform and the extra flags both become part of the rebuild tag in =$(BUILDDIR)/.raylib-platform=.

With none of them set, every command is exactly the in-tree one. Requires =rsync= for the out-of-tree case.

**** Limitations
:PROPERTIES:
:CUSTOM_ID: limitations
:END:
- GObject Introspection (.gir/.typelib) is disabled when cross-compiling
- Running Windows executables requires Wine or a Windows machine
- Python bindings are not available for cross-compiled builds

*** Android
:PROPERTIES:
:CUSTOM_ID: android
:END:
graylib builds for Android on arm64-v8a with the NDK's clang, as libregnum's =android-arm64= target does (=make ANDROID=1= there; its build container has the NDK and a static GLib stack):

#+begin_src sh
make BUILDDIR=/tmp/gl-android RAYLIB_BUILD_DIR=/tmp/raylib-android \
     CC=$NDK/toolchains/llvm/prebuilt/linux-x86_64/bin/aarch64-linux-android29-clang \
     AR=$NDK/toolchains/llvm/prebuilt/linux-x86_64/bin/llvm-ar BUILD_GIR=0 \
     RAYLIB_PLATFORM=PLATFORM_ANDROID \
     RAYLIB_EXTRA_FLAGS="ANDROID_NDK=$NDK ANDROID_ARCH=arm64 ANDROID_API_VERSION=29 GRAPHICS=GRAPHICS_API_OPENGL_ES3"
#+end_src

=RAYLIB_PLATFORM=PLATFORM_ANDROID= builds raylib's Android layer (=rcore_android.c=, the NativeActivity glue) and makes graylib link EGL, GLES 3, libandroid and liblog. Compiled with =-DGRL_PLATFORM_ANDROID=, graylib leaves out what needs GLFW: the window's GLFW pre-flight, the input event-modifier callbacks (=grl_input_event_mods_init()= returns =FALSE=; input is polled) and clipboard images (=grl_window_get_clipboard_image()= returns =NULL=; text works). clang reports graylib's identical typedef redefinitions as a C11 extension in gnu89; the Android flags add =-Wno-typedef-redefinition= (gcc accepts them as GNU C), and every other warning stays on.

** Troubleshooting
:PROPERTIES:
:CUSTOM_ID: troubleshooting
:END:
*** pkg-config not finding GLib
:PROPERTIES:
:CUSTOM_ID: pkg-config-not-finding-glib
:END:
Ensure pkg-config can find glib:

#+begin_src sh
pkg-config --cflags --libs glib-2.0
#+end_src

If not found, check that =PKG_CONFIG_PATH= includes the glib .pc file location.

*** raylib build fails
:PROPERTIES:
:CUSTOM_ID: raylib-build-fails
:END:
Ensure all X11 development packages are installed:

#+begin_src sh
# Fedora
sudo dnf install libX11-devel libXrandr-devel libXi-devel \
    libXcursor-devel libXinerama-devel

# Check OpenGL
glxinfo | head
#+end_src

*** GIR scanner fails
:PROPERTIES:
:CUSTOM_ID: gir-scanner-fails
:END:
Ensure gobject-introspection is installed:

#+begin_src sh
which g-ir-scanner
g-ir-scanner --version
#+end_src

*** Library not found at runtime
:PROPERTIES:
:CUSTOM_ID: library-not-found-at-runtime
:END:
Set =LD_LIBRARY_PATH=:

#+begin_src sh
export LD_LIBRARY_PATH=/path/to/graylib/build/lib:$LD_LIBRARY_PATH
#+end_src

Or install the library system-wide:

#+begin_src sh
sudo make install
sudo ldconfig
#+end_src
